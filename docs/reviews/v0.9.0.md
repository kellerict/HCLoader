# Review v0.9.0 – statistics, Windows notifications, Plex/Jellyfin

Range: `git diff c02c56d..HEAD`. I only spot-checked the translation catalogs (`notify.*`, `cli.open` in `de`/`en`).
Reviewer: independent `reviewer` agent; no code was changed.
Local run: `pytest tests/test_notify.py tests/test_stats.py tests/test_mediaserver.py tests/test_stats_ui.py
tests/test_db.py`, the i18n/parity tests and `ruff check .` all pass.

## Verdict: **ÄNDERUNGEN NÖTIG**

No Blocker. There is one Major. The `hcloader:` protocol handler starts the full CLI parser with an argument from
a link, and `main()` checks `--smoke` and `--run-watchlist` before `--open`. A link that gets a quote past the
browser could therefore start a real download or a watchlist run (M1). The fix is small. Everything else is in
good shape. YouTube is not touched: no new path to yt-dlp and nothing goes around the `Throttle`.

## Checked and in order

- **YouTube/Throttle:** v0.9.0 adds no yt-dlp call. Statistics and size measuring only use the DB and a local
  `stat`. The notification and media-server hooks run after the queue run or the headless run
  (`worker.py` `on_session_end`, `headless.py:_after_run`) and do not change its result: there is a
  `try/except` around them. `yt_dlp` is still only imported in `ytclient.py`. `core/` has no UI code, and the
  new `api.py` methods only delegate.
- **Toast invocation:** `-EncodedCommand` (UTF-16LE base64) with a fixed script. The XML and the AppID travel in
  environment variables, so no part of a title is ever parsed as PowerShell. Titles and bodies go through
  `xml.sax.saxutils.escape` into text nodes, and the `launch` attribute goes through `quoteattr` and only allows
  views from a whitelist (`notify.py:173-184`). The runtime is bounded (`timeout=20`, and `subprocess.run` kills
  the process), `CREATE_NO_WINDOW` plus `-WindowStyle Hidden` hide the console, and stderr is cut to 300 chars.
  The optional pywinrt path loads the same XML. If no backend is available, the event is only logged.
- **Aggregation/quiet hours:** one batch is kept in `state.notify_pending` (titles capped at 3, 60 chars each).
  The GUI waits 15 s after the last event and keeps at least 120 s between two toasts. During quiet hours the
  batch is held and sent afterwards as one summary; a range that crosses midnight and `from == to` are both
  handled. A failed send is dropped, not retried. The ticker polls every 30 s, which is cheap.
- **Single-instance forwarding:** `show <token> <view>` is sent only with `VIEW_RE` `[a-z]{2,20}`, and the view
  is checked again against `NAV_VIEWS` (`api.open_view`) and `VIEWS` in `app.js`. Without the token from
  `activation.json`, nothing happens. A view only switches navigation.
- **Plex/Jellyfin transport:** `ProxyHandler({})` (no proxy), redirects are refused (`_NoRedirect`, so a token
  header never follows a 30x), the response is capped at 2 MB, the timeout is 10 s and there are no retries.
  `verify_tls` defaults to true. The URL validator rejects other schemes, userinfo, query and fragment. Tokens go
  through `clean_secret`, which strips control characters (no header injection), and Jellyfin rejects `"`/`,` in
  the `MediaBrowser` header. Error texts contain only the reason or status, never the token or headers. The token
  is stored only after a successful test.
- **Credential Manager ctypes:** the `CREDENTIALW` layout matches `wincred.h`, and `CredReadW`, `CredWriteW`,
  `CredDeleteW` and `CredFree` have correct argtypes and restypes. The blob is UTF-16LE with `CredentialBlobSize`
  in bytes. `MAX_SECRET` is 512 chars, which is 1024 bytes and below `CRED_MAX_CREDENTIAL_BLOB_SIZE` (2560).
  `CredFree` is called in `finally`, and `ERROR_NOT_FOUND` is handled.
- **Migration 15:** it is additive (`ADD COLUMN file_size`, a new index name), and `file_size` is written at the
  only place that sets `file_path` (`db.py:882-886`, `set_file_path`) and cleared in `mark_removed`. The backfill
  runs in its own worker thread in batches of 200 transactions, can be cancelled at `stop()`, and has the guard
  `AND file_size IS NULL` so it never overwrites a value.
- **Stats SQL:** all values are bound as parameters. Only internal column names are formatted into the SQL
  (`_where`). Date input is checked with a regex and `date.fromisoformat`, and a reversed range is swapped. The
  queries use `idx_videos_downloaded`.
- **XSS in the statistics view:** every DB string (genre, festival, DJ, track, source name, `initials`, `key`)
  goes through `esc()` (`stats.js:63-221`). Colors come from `GenreItem.color`, which is validated as
  `^#[0-9a-fA-F]{6}$`, and are escaped as well. The media-server panel escapes server name, version, library
  names and paths, all of which come from a foreign server.
- **i18n:** new keys exist in all catalogs and the parity tests are green. `de` uses «ss».
- **Hygiene:** no tokens or real paths in tests or docs. The installer only adds `uninsdeletekey` and
  `dontcreatekey` for the two HKCU keys.

## Major

### M1 – `hcloader:` link can reach `--smoke` / `--run-watchlist` (argument injection)

`app/core/notify.py:362-368` registers
`"<pythonw>" -X utf8 -c "<code>" --open "%1"`. `%1` is the raw URL from the browser or other caller.
`app/main.py:371` (`if args.smoke`) and `:382` (`if args.run_watchlist`) are checked **before** `--open` is
looked at (`view_arg` at :39 only runs later). The parser is the full `build_parser()`.

**Scenario:** a caller that passes a URL without percent-encoding (older or third-party launchers, mail and
office clients, a `ShellExecute` from another program) opens
`hcloader://x" --smoke "https://attacker.example/a.mp3`. Windows splits this into
`--open "hcloader://x" --smoke https://attacker.example/a.mp3`. HCLoader then runs a real yt-dlp download of an
arbitrary URL (generic extractor) into the library, or with `" --run-watchlist` a full watchlist run with
YouTube access and auto-download, without user action. This is the same pattern as the Electron CVE-2018-1000006.
Current Chrome, Edge and Firefox percent-encode `"` and spaces, so the risk today is smaller. But the brief
explicitly says a link may only navigate, and the protection must not depend on the browser.

**Proposal (any one of these is enough; the first two together are best):**
1. Register a dedicated entry that takes exactly one argument and parses nothing else, for example
   `... -c "<code>" --protocol "%1"`. In `main()`, `--protocol` is handled *first*: if `argv` has anything
   besides exactly `["--protocol", <value>]`, exit with `EXIT_USAGE` before any other flag is looked at. Then use
   only `view_arg(value)` and `run_gui`/`request_activation`.
2. Alternatively, in `main()`: if `args.open` is set together with `smoke`, `headless` or `run_watchlist`,
   refuse right away (before line 371).
3. Add a test: `main(["--open", 'hcloader://x', "--smoke", "u"])` must not call `run_smoke`. Also check the
   registry string from `protocol_command` (`--open "%1"` is the last argument and nothing follows).

## Minor

- **m1 – Backfill writes 0 for files on an offline drive, forever** (`app/core/stats.py:403-407`,
  `db.file_size_of`). `file_size_of` returns `None` for every `OSError`, including when a NAS or USB target
  folder is not mounted. `measure_sizes` then writes 0 and never measures again (by design, «fehlende Datei = 0»).
  **Scenario:** a user opens Statistics while the NAS is offline, and the total size stays wrong until each set is
  downloaded again. **Proposal:** before a batch, check that `target_dir` (or the file's root) is reachable. If it
  is not, stop without writing. Write 0 only for `FileNotFoundError` when the parent drive exists.
- **m2 – Test connection sends the stored token to a URL that was not saved** (`app/api.py` `test_media_server`,
  `secret = secret or self._media_secret(kind)`). If the user changes the address (or mistypes it as a public
  host) and clicks «Test», the stored Plex token goes to the new host, over plain `http` if that is what was
  entered. **Proposal:** use the stored secret only if `url` equals the saved `media_server.url`. Otherwise ask
  for the token again, or at least show a notice for `http://` to a non-private host.
- **m3 – A credential blob of odd length raises an uncaught `UnicodeDecodeError`** (`app/core/credentials.py:136`).
  Another tool could write a target named `HCLoader/media_server/plex`. `_media_secret` only catches
  `CredentialError`, so `get_media_server_status` and `run_scan` raise (`run_scan` catches it generically, but the
  status view does not). **Proposal:** use `decode("utf-16-le", "strict")` inside a `try` that raises
  `CredentialError`.
- **m4 – Control characters in a set title make the toast XML invalid** (`notify.py:140-142`, `toast_xml`).
  `escape()` does not remove characters such as `\x01` or `\x0b`, which are illegal in XML 1.0. Such a title can
  come from YouTube. `LoadXml` then fails and the whole batch toast is dropped, but only logged.
  **Proposal:** in `_short`, remove `[\x00-\x08\x0b\x0c\x0e-\x1f]`.
- **m5 – Month buckets use UTC, the range uses local time** (`stats.py:219`, `_months` `lo[:7]`). In UTC+1/+2,
  `from = 2026-01-01` becomes `2025-12-31T23:00Z`. The chart then starts with an empty December, and a download at
  00:30 local time on the 1st is counted in the previous month. **Proposal:** take the first month from
  `rng["from"]` and group by local month (offset from the client, or `datetime(...).astimezone()` in Python
  after the query).
- **m6 – Possible double toast from GUI and headless** (`notify.flush`): `_lock` only works inside one process.
  If a scheduled run and the GUI flush the same batch at the same time, it can be shown twice. **Proposal:** do
  the read, delete and `STATE_LAST` update in one DB transaction with `BEGIN IMMEDIATE`, and send only when this
  process actually deleted the batch.
- **m7 – No Python isolation in the protocol command** (`notify.py:367`). Because of `-c`, `''` (the current
  directory of the caller) stays on `sys.path` after the inserted root, so a module that is not in the app could
  be loaded from there. **Proposal:** use `-P` (Python 3.11+) or `-I` together with the explicit
  `sys.path.insert`.

## Nits

- `stats.py:162` hard-codes `"Unsortiert"`. Use the `config.UNSORTED` constant.
- When `_retag` rewrites tags without moving the file, `file_size` is not updated. This is a small byte drift and
  can be ignored, or fixed by calling `file_size_of` after `write_tags`.
- The `urllib` timeout applies to each socket operation, not to the whole request. A server that drips data can
  run longer than 10 s, although the API call still ends after `MEDIA_*_TIMEOUT_S`.
- `get_stats` runs in the playlist thread (`_pl`). A long M3U8 export blocks the statistics view until it is done.

## Nachtrag (integrator, 2026-11-18)

Behoben:

- **M1:** Eigener Protokoll-Einstieg `"<pythonw>" -X utf8 -I -c "…" --protocol "%1"` (`notify.protocol_command`).
  `main()` prüft `--protocol` vor allem anderen: nur genau `["--protocol", <url>]`, sonst `EXIT_USAGE` ohne
  Aktion. `protocol_view` erlaubt nur `hcloader://open/<view>` (bzw. `hcloader://<view>`) mit
  `inbox|downloads|library|stats`, nur `A-Za-z:/`, max. 64 Zeichen, kein Dekodieren. Ein gültiger Link leitet nur
  weiter oder startet die GUI an der Ansicht (keine Update-Wiederherstellung). `--open` mit `--smoke`,
  `--headless` oder `--run-watchlist` → `EXIT_USAGE`; Parser mit `allow_abbrev=False`. Toasts starten
  `hcloader://open/<view>`. `notify.refresh_registration` schreibt beim GUI-Start einen vorhandenen HKCU-Eintrag
  (alter `--open "%1"`-Befehl) um; nicht quotierbarer Pfad → alter Befehl wird gelöscht. Uninstaller:
  `uninsdeletekey` (unverändert). Tests: präparierte URLs/Argumente (Anführungszeichen, Leerzeichen,
  `%22 --smoke …`, Zusatzargumente, `--protocol=…`, Abkürzungen) → kein Smoke/Watchlist/GUI/Aktivierung.
  Entscheid in `docs/decisions.md`.
- **m1:** `measure_sizes` prüft je Laufwerk/Freigabe die Erreichbarkeit; offline → Zeile bleibt ungemessen
  (`offline` im Ergebnis/Event), 0 nur bei erreichbarem Laufwerk.
- **m2:** «Verbindung testen» nutzt das gespeicherte Token nur für die gespeicherte Adresse, sonst `no_secret`.
- **m3:** Ungültiger UTF-16-Blob → `CredentialError`. Neu: `tests/test_credentials.py` mit ctypes-Fake von
  advapi32 (Unicode, fehlender Eintrag, Fehlercodes, `CredFree`, Blob-Grösse).
- **m4:** `_short` entfernt XML-1.0-unzulässige Steuerzeichen (Zeilenumbrüche werden zu Leerzeichen).
- **m5:** Monate nach lokaler Zeit (`strftime('%Y-%m', …, 'localtime')`, Grenzen über `astimezone()`); Test mit
  `TZ=CET-1` am Jahreswechsel.
- **m6:** `notify.add`/`flush` lesen und schreiben den Stapel in einer `BEGIN IMMEDIATE`-Transaktion
  (`Database.transaction(immediate=True)`); Test mit zwei Verbindungen → ein Toast.
- **m7:** `-I` im Protokollbefehl.
- **Nits:** `UNSORTED`-Konstante in `stats.py`; `_retag` aktualisiert `file_size` auch ohne Verschieben.

Akzeptiert (nicht geändert):

- `urllib`-Timeout pro Socket-Operation: Antwort ist auf 2 MB begrenzt, der Scan läuft im eigenen Thread und
  blockiert weder Queue noch UI; ein «tröpfelnder» eigener Server ist kein realistisches Risiko.
- `get_stats` im Playlist-Thread: M3U8-Exporte dauern Sekunden; ein eigener Thread lohnt sich derzeit nicht.
