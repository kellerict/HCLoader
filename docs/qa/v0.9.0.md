## 2. Notifications - Bestanden
- Aggregation: `notify.add` collects in `state.notify_pending`, one toast per batch (`build`), 120 s min gap, GUI debounce 15 s
  (`NotificationService`), tests green. Per-event switches (`new_sets`, `downloads_done`, `downloads_failed`, `enabled`) honoured in `add`.
- Quiet hours incl. midnight wrap (`start > end`) and from == to (all day): parametrized `test_quiet_hours` green; batch is kept and sent after.
- Headless: `notify_run` (never raises) + `test_headless_run_shows_one_aggregated_toast`. Sender failures are caught in `flush` (reason `error`) -> no crash.
- PowerShell safety: fixed script passed as `-EncodedCommand` (UTF-16LE base64); toast XML and AppID travel in environment variables,
  so set titles never reach the command line or the script text. XML via `xml.sax.saxutils.escape` / `quoteattr`. `PS_TIMEOUT_S = 20`,
  `CREATE_NO_WINDOW`, `-WindowStyle Hidden`, `-NoProfile -NonInteractive`, absolute path to Windows PowerShell 5.1. Tested with a mocked runner.
- Finding (minor, at HEAD): control characters (e.g. `\x01`) in a title are not stripped, so `LoadXml` would fail and that toast is lost
  (swallowed, logged). The uncommitted working-tree edit adds `_XML_ILLEGAL` stripping; verify when committed.
- Protocol: `ensure_registered` writes only under `HKCU\Software\Classes\hcloader` and `...\AppUserModelId\HCLoader.App`, idempotent, only when enabled
  (fake-winreg test). Announced in `CODE_SIGNING.md` and the installer privacy text; installer `[Registry]` has
  `uninsdeletekey` entries for both keys. `--open` is whitelisted (`view_arg`), activation message validated by `VIEW_RE` + token.
- Minor: registration is done by the app at runtime, not by the installer (documented, consistent).

## 3. Plex / Jellyfin - Bestanden (one gap)
- Request building per docs verified in `scan_requests` and tests (`test_plex_scan_requests`, `test_jellyfin_scan_requests`): Plex
  `GET /library/sections/<id>/refresh?path=`, `X-Plex-Token` header; Jellyfin `POST /Library/Media/Updated`, `/Items/<id>/Refresh`,
  `/Library/Refresh`, MediaBrowser Token header. Token never in URL. Test connection = `/` + `/library/sections` resp. `/System/Info` + `/Library/VirtualFolders`.
- Batching/debounce: `MediaScanQueue` (timer restarted per download, one batch at a time, Plex max 5 folders, Jellyfin max 100 paths, no retries).
- Timeouts/safety: 10 s, response capped at 2 MiB, system proxy bypassed, redirects refused (token not forwarded), TLS verify configurable.
- Secrets: no secret field in settings (`test_settings_have_no_secret_field`); `test_api_test_connection_stores_secret_only_after_success`
  and `test_api_scan_now_and_save_settings_keep_secret_out` check caplog/config for the token. Works unconfigured (`type: off` -> `add` returns False, `run_scan` -> config error, no crash).
- Mängel:
  1. `WindowsCredentialStore` (ctypes `CredWriteW/ReadW/DeleteW`) is `# pragma: no cover` and has NO mock-based unit test
     (only `MemoryStore`, `clean_secret`, `target`). The requested "Credential Manager code paths unit-tested with mocks" is not met; it can only be
     verified on Windows. Recommend a test with a fake `advapi32` (monkeypatched `ctypes.WinDLL`) or a manual Windows check before release.
  2. `run_scan` logs `exc_info=True` for unexpected exceptions; no secret is in the URL/headers, so currently safe, but relies on library exception texts.
