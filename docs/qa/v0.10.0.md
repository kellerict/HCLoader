## 1. Fingerprint: Bestanden

- Lowpass only: 0.246, match.
- Different sets (3 seeds): score 0.03-0.04, 24-31 hits, no match.
- 200 random unrelated pairs (40 items x 20 s): 0 false positives.
- Index lookup, 10k items x 1500 index rows (15 M rows): `candidates()` 1.4 ms.
- Repo tests (all green): marks, actions keep/link/delete (`test_resolve_actions_and_forget`), backfill progress and cancel, errors not retried, precheck sends re-upload to inbox instead of queue (nothing downloaded twice), migration 16.

Observation O1 (not a failure): on this harsh synthetic signal, strong additive white noise or coarse quantisation drops the score to 0.06-0.17, below the default `reupload.min_score` 15 % (hits 46-144, above MIN_HITS 20). Real codec re-encodes were not measurable without ffmpeg; the repo test covers noise+offset+gain. Users may need to lower min_score for heavily degraded uploads.
